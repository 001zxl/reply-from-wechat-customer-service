## 方言 / 当地说法对照（选填，但很有用）

语音是机器转写的，带口音就容易转错。把你们那边常听到的说法写上，
AI 理解语音时会**优先按这张表**。

例（把左边的换成你们当地的说法）：

| 客户可能这么说（语音转写出来的） | 实际意思 |
|---|---|
| 到哪哈了 / 到哪了哈 | 这票到哪了 |
| 推回来 / 腿回去 | 退回 |
| 该地方 / 改地儿 | 改址 |
| 多处钱 / 咋收费 | 问运费 |
| 收了没 / 到没到 | 签收确认 |
| 破了 / 烂了 | 破损 |
| 找不着了 / 没影了 | 丢件 |

行业黑话也写这里，比如某个客户对"大货""小包""电商件"的特殊叫法。
