========================================================
  微信客服助手 - 使用说明
========================================================

这是一个微信客服助手，能在微信里自动理解商家发来的消息、
查物流、生成回复。详细的介绍见项目根目录的说明文档。


--------------------------------------------------------
  开始之前，先确认三件事
--------------------------------------------------------

  1. 这台电脑上装的是【个人微信】，并且已经登录
     （企业微信不行）

  2. 微信窗口不要最小化。程序靠"看屏幕"来读消息，
     窗口被最小化或者被别的窗口完全盖住就读不到了。

  3. 准备好一个 DeepSeek 的 API Key
     · 去 https://platform.deepseek.com 注册
     · 在左侧「API Keys」里创建一个
     · 复制出来（以 sk- 开头的一长串）
     · 需要先充值，几块钱就够测很久


--------------------------------------------------------
  安装（按顺序双击这四个文件）
--------------------------------------------------------

  1-install.bat
      自动装 Python 和依赖。约 5-15 分钟。
      中途不要关窗口。

  2-config.bat
      弹出配置窗口，粘贴你的 API Key。
      点「测试连接」看到绿色的 ✓ 就说明没问题，
      然后点「保存」。

  3-start.bat
      启动程序。会自动打开浏览器。
      ★ 这个黑色窗口要一直开着，关掉就等于停止服务。

  4-diagnose.bat
      出问题时才需要跑。生成一份诊断报告，
      把报告和截图发给对方，帮你排查。


--------------------------------------------------------
  第一次使用
--------------------------------------------------------

  浏览器打开之后是「审核台」。第一次要做的是
  告诉程序"可以跟哪些人聊天"：

    1. 点左侧「会话白名单」卡片里的【扫描微信会话】

    2. 下面会列出你微信里的会话，勾选你想让 AI 服务的
       那几个（比如你的客户、商家群）

    3. 点【保存勾选】

  ★ 没勾选的会话，程序**打不开也读不到**。
    这是故意的，保护你的其他聊天记录。


--------------------------------------------------------
  平时怎么用
--------------------------------------------------------

  商家发消息过来
        ↓
  AI 理解之后生成一条草稿
        ↓
  你在审核台看到草稿，点【发送】才真的发出去
  （也可以先改一改再发）

  不想让 AI 管的会话 → 点那个会话的【接管】按钮，
  AI 就完全不碰了。


--------------------------------------------------------
  建议先这样试
--------------------------------------------------------

  第一次用，建议只勾 1-2 个不太重要的会话，
  观察一两天，看看 AI 回得怎么样。

  确认靠谱之后，再在配置里改成「全自动」。

  ★ 默认是「审核模式」——AI 只出草稿，绝不会自己发出去。
    这个模式下不可能误发消息，可以放心试。


--------------------------------------------------------
  常见问题
--------------------------------------------------------

  Q: 黑窗口里报错 "找不到微信主窗口"
  A: 微信没登录，或者窗口被最小化了。把微信打开再重启程序。

  Q: 程序读不到消息 / 读到的消息不全
  A: 检查微信窗口有没有被别的窗口挡住。程序靠截图读字，
     窗口必须能看见。

  Q: 点【测试连接】提示 401
  A: API Key 不对。重新复制一次，注意别漏字符。

  Q: 点【测试连接】提示 402
  A: DeepSeek 账户余额不足，去后台充值。

  Q: 扫描会话列表是空的
  A: 版面没标定对。跑 4-diagnose.bat 把报告发过来。

  Q: 会不会封号？
  A: 任何个人微信自动化都有风险，没人能保证绝不封号。
     不过这个程序不注入微信进程、不修改微信文件，
     只是截屏 + 模拟鼠标键盘，行为特征接近真人。
     而且默认只出草稿、人工点发送，比机器刷屏安全得多。
     详细说明见项目里的功能说明书。

  Q: 我的聊天记录会被上传吗？
  A: 只有你勾选在白名单里的会话，内容会发给大模型 API
     用于生成回复。没勾选的会话程序打不开。
     其它记录不会被读取。


--------------------------------------------------------
  要停下来
--------------------------------------------------------

  在那个黑窗口里按 Ctrl+C，或者直接关掉窗口。


--------------------------------------------------------
  想卸载
--------------------------------------------------------

  整个文件夹删掉就干净了，不写注册表、不装系统服务。
  只额外产生两个地方的文件：
    · C:\Windows\Temp\wechat_cs_probe  （诊断时生成的截图）
    · 安装 Python 时装的 Python 本身
